# Release Notes

## Version 2026.08.14-1 — Production update

- Added localized UI support for English, French, German, Italian, Portuguese,
  and Spanish.
- Linked QRZ callsigns to their QRZ profile pages.

## Version 2026.08.10-1 — Marketplace preparation in progress

Initial planned public release of Browser for QRZ for Google Sheets™.

### Highlights

- Read-only import and browsing of QRZ Logbook QSO and QSL data in Google
  Sheets™.
- Native Sheets sorting, filtering, search, and charting for downloaded data.
- Complete QSO and QSL ADIF field views.
- Incremental update checks for an imported date range.
- Included demo contacts for a no-credential evaluation path.
- QRZ callsigns and API keys are used only for live requests and are not
  retained.
